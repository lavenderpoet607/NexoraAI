nexora-advanced-intelligence

Skill ini dirancang untuk meningkatkan kemampuan kerja AI coding agent di Antigravity dan platform agent lain yang kompatibel.

Fokus utama:

- Advanced Thinking dan problem solving
- Deep reasoning workflow
- Adaptive thinking modes
- Context engineering
- Automatic context compacting

- Automatic project cache
- Cross-chat context restoration
- Incremental repository analysis
- Multi-agent orchestration
- Subagent coordination
- Token optimization
- Autonomous development
- Self-review dan error recovery
- Automatic testing
- Automatic test cleanup
- Project continuity
- Long-running task management

Hasil akhir wajib berupa satu file utama:

nexora-advanced-intelligence/SKILL.md

Jangan membuat satu file SKILL.md untuk setiap fitur. Semua kemampuan harus berada dalam satu skill terpadu.

## 24. AUTOMATIC TEST CLEANUP

Implementasikan fitur Auto Test Cleanup.

Tujuan:

Membersihkan seluruh test sementara dan artefak pengujian yang dibuat khusus selama pengerjaan setelah pengujian selesai.

Klasifikasikan file pengujian menjadi:

A. Temporary Test Files
File pengujian sementara yang dibuat oleh agent untuk tugas saat ini.

B. Test Artifacts
Log sementara, screenshot pengujian, hasil simulasi, temporary build output, coverage sementara, dan file hasil eksekusi yang tidak diperlukan.

C. Existing Test Suite
Test suite yang sudah ada sebelum pekerjaan dimulai.

D. Permanent Test Infrastructure
Konfigurasi test, CI workflow, test fixture, mock, helper, test data, dan file yang dibutuhkan untuk pengujian proyek.

E. User-Owned Test Files
File pengujian yang dibuat atau dikelola pengguna.

Aturan penghapusan:

1. Inventarisasi seluruh file test sebelum perubahan.
2. Catat file test yang dibuat oleh agent.
3. Tandai artefak sementara yang boleh dibersihkan.
4. Jalankan semua pengujian yang diwajibkan.
5. Verifikasi hasil pengujian.
6. Simpan laporan hasil pengujian.
7. Hapus temporary test files yang dibuat agent jika sudah tidak diperlukan.
8. Hapus temporary test artifacts.
9. Bersihkan temporary directory.
10. Periksa kembali repository setelah cleanup.
11. Pastikan tidak ada file penting yang ikut terhapus.
12. Perbarui cache setelah cleanup.

Pengamanan:

- Jangan menghapus existing test suite secara otomatis.
- Jangan menghapus test yang diperlukan CI/CD.
- Jangan menghapus test fixture dan mock yang masih digunakan.
- Jangan menghapus test milik pengguna.
- Jangan menghapus konfigurasi testing.
- Jangan menghapus database atau data proyek.
- Jangan menghapus file hanya karena namanya mengandung kata test.
- Jangan menggunakan perintah penghapusan massal tanpa daftar target yang jelas.

Jika pengguna secara eksplisit meminta seluruh test suite permanen dihapus:

1. Tampilkan daftar file yang akan dihapus.
2. Jelaskan dampaknya.
3. Minta persetujuan sebelum penghapusan.
4. Hapus hanya file yang telah disetujui.
5. Pertahankan laporan hasil pengujian.

Jangan menghapus source test sebelum seluruh pengujian yang relevan selesai.

Jika pengujian gagal, pertahankan file yang diperlukan untuk debugging sampai masalah ditangani atau pengguna memutuskan untuk menghentikannya.

Laporan harus mencatat:

- Total test dijalankan
- Total PASS
- Total FAIL
- Total SKIPPED
- Temporary files created
- Temporary files removed
- Permanent test files preserved
- Cleanup status

Jangan mengklaim cleanup berhasil tanpa memeriksa kondisi repository setelah penghapusan.

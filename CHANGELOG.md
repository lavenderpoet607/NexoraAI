# Changelog

All notable changes to the NEXORA AI project will be documented in this file.

## [1.0.0] - 2026-11-08

### Added
- Complete catalog of exactly 3,000 unique, validated agent skills across 16 domains.
- Universal JSON Schema draft-07 specification in `schemas/skill_schema.json`.
- SQLite FTS5 instant search engine and content-hashed caching system.
- Native multi-platform export engine for Antigravity, Claude Code, Cursor, Windsurf, Copilot, Cline, Roo Code, Gemini CLI, Codex, Continue, and Aider.
- Active multi-agent orchestration architecture featuring 5 specialized subagent roles.
- Automated testing suite verifying schema conformance, absence of comments, and registry integrity.
- Unified Command Line Interface (`nexora`).
